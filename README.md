# SLR GRAPHICS — Modern Creative Design Studio Website

Official website for **SLR GRAPHICS** — a modern creative design studio positioning brands through distinctive visual identities, social media campaigns, print & packaging, and digital interfaces.

---

## 🎨 Visual Identity & Style System

| Element | Specification | Hex / Value |
| :--- | :--- | :--- |
| **Main Background** | Pure Crisp White Canvas | `#FFFFFF` |
| **Dark Purple** | Primary Text, Headings & Footer | `#1B1035` |
| **Violet** | Section Labels, Accents & CTAs | `#7C3AED` |
| **Bright Violet** | Hover States, Highlights & Gradients | `#A855F7` |
| **Card Style** | White Surface with Dark Purple 1px Border | `#FFFFFF` with `1px solid #1B1035` |
| **Card Hover/Tap** | Dynamic Invert to Dark Purple | `#1B1035` bg with `#FFFFFF` text & `#A855F7` accent |
| **Typography** | Bold Display Headings | `Space Grotesk`, `Syne` |
| **Typography** | Editorial Body Text | `Plus Jakarta Sans` |

## 📱 Mobile Layout Update (3 × 2 Grid System)

For mobile screens, the website organizes content into a compact **3-column, 2-row grid** (6 boxes total) with 8–12px balanced spacing and no horizontal overflow:

1. **SERVICES (3 × 2 Grid)**:
   - **Row 1**: `[01 Brand Identity]` `[02 Social Media]` `[03 Advertising]`
   - **Row 2**: `[04 Print & Packaging]` `[05 UI/UX & Web]` `[06 Custom Design]`
2. **PORTFOLIO (3 × 2 Grid)**:
   - **Row 1**: `[Project 01]` `[Project 02]` `[Project 03]`
   - **Row 2**: `[Project 04]` `[Project 05]` `[Project 06]`
   - **Interactive Modal**: Tapping any card opens a full-screen mobile Case Study view.
3. **ABOUT (3 × 2 Grid)**:
   - **Row 1**: `[01 Creative Thinking]` `[02 Professional Design]` `[03 Brand Consistency]`
   - **Row 2**: `[04 Attention to Detail]` `[05 Strategy]` `[06 Client Focus]`

1. **HOME**: Hero section with *“CREATE. DESIGN. STAND OUT.”*, creative ribbon logo showcase, and key studio metrics.
